# Member text style

House style approved by Ruggie in decision D7, 2026-11-21.

1. Start with the main point in one sentence; skip it when the heading already says it.
2. Put required actions in a numbered list, one instruction per item.
3. Put facts in bullets, one fact per bullet.
4. Use question headings in WU FAQ and help posts only.
5. Use short sentences, active voice and the same word for the same thing. Use “select”, never choose/click/pick/tap; never “the bot”.
6. Never change a fact, condition or warning to shorten text.

Keep the WU voice: emoji headings and banter. Do not apply the AR 25-50 memo format,
a “BLUF:” label, or a reason line on every post.
