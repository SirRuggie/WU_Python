# Clash of Clans API wrapper (community-maintained).
#
# NOTE: an earlier version of this comment cited a "3.9.2" release for the
# utcnow and non-JSON fixes. THERE IS NO 3.9.2. PyPI has 3.9.0, 3.9.1, 3.10.0,
# 4.0.0 and nothing else. Both fixes are in 3.10.0.
#
# Taken from 3.9.1 for three reasons, all read from the v3.9.1...v3.10.0 diff:
#
#   1. Removes every datetime.utcnow() call - 6 in coc/utils.py plus
#      coc/miscmodels.py and coc/http.py - replacing them with
#      datetime.now(tz=timezone.utc).replace(tzinfo=None). Identical naive-UTC
#      value, so no behaviour change. This is what ends the ~200
#      DeprecationWarning lines per /todo run under Python 3.12.
#   2. coc/raid.py: max(*[...], self.stars) -> max([self.stars] + [...]). The
#      old form raises TypeError when a raid member has destruction but no
#      recorded attacks, because max(int) is not iterable. That is a live crash
#      in the /todo raid path, not a theoretical one.
#   3. coc/http.py: (await resp.json())["keys"] -> .get("keys", {}). Hardens
#      login against a response that is not the expected JSON - directly
#      relevant, since every call here goes through the proxy.clashk.ing
#      third party, which can return an error page during an outage.
#
# Safe as a drop-in: nothing was removed from the public API, the six client
# methods used here all still exist, and the bulk of the diff is static game
# data JSON which is inert - main.py sets load_game_data=LoadGameData(default=
# False). requires-python is >=3.10.0; the box is 3.12.3.
#
# 4.0.0 exists (2025-12-06) and is NOT taken. It is a major: static data is
# always loaded, coc.enums lists moved to coc.constants, Troop/Hero/Spell
# attributes changed type or were removed, and create_army_link was deleted.
# Our surface is narrow enough that it might well be fine, but a major bump is
# its own project with its own testing, not a pin edit.
# See docs/hikari-lightbulb-versions.md.
coc.py==3.10.0
